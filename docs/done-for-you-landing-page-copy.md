## FAQ

### Is this a monthly subscription?

No. The done-for-you setup starts at a one-time $299 setup fee. There is no required monthly software fee for the plugin.

### Does this work for my industry?

It is designed for local service businesses that use estimate requests, including roofing, windows, siding, HVAC, plumbing, landscaping, remodeling, pest control, and similar services.

### Can you build more than one form?

Yes. The starting setup includes one estimate form. Additional forms or advanced customization can be quoted separately.

### Will this give customers a final quote?

No. It is designed to provide estimate ranges and capture qualified project details. You can still review each project before giving a final proposal or contract.

### Do I need WordPress?

Yes. Instant Estimate Builder is a WordPress plugin.
